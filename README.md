## Overview

iZotope Ozone is a comprehensive mastering suite with AI-driven assistants, multiband dynamics, stereo imaging, and a full mastering signal chain in one plugin.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **iZotope Ozone** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Master Assistant** | AI analyzes audio and configures a starting mastering chain |
| **Multiband Dynamics** | Independent compressor and limiter per frequency band |
| **Stereo Imager** | Multiband stereo width control with phase coherence monitoring |
| **Maximizer** | Intelligent brick-wall limiter with multiple modes for different sources |
